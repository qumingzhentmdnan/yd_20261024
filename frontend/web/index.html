如何安全使用 SafeAgent
先选择项目文件，再输入模型地址和一次性 API Key。Host 会把项目副本送入隔离 VM，Agent 只能通过受限代理访问模型。
  1. 读取项目候选文件并取消不需要的内容。
  2. 启动会话，在终端中与 Agent 对话。
  3. 停止后查看 Diff，确认后才回写宿主项目。
API Key、MCP Token 和 GitHub Token 都不会进入 Guest。
